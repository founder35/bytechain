## About

ByteChain is a fast, cost-efficient Proof-of-Stake EVM blockchain
built using the [Cosmos SDK](https://github.com/cosmos/cosmos-sdk/)
and [CometBFT](https://github.com/cometbft/cometbft) consensus engine.
It is designed to support real-world use cases including RWA (Real-World Assets),
tokenization, DeFi, and NFT applications — powering the broader
[Byte Exchange](https://bexc.io) ecosystem.

$BEXC is the native asset of ByteChain, used for staking, validator nodes,
ecosystem participation, and on-chain utilities.

For prerequisites and detailed build instructions,
please read the Installation section in the documentation.
Once the dependencies are installed, run:

## Staking & Nodes

ByteChain supports validator node participation and staking of $BEXC.

- **Total node rewards:** 15,000,000 BEXC distributed over 120 months
- **Stake & Earn:** [trade.bexc.io/stake](https://trade.bexc.io/stake)
- **Buy a node:** [bytepad.io](https://v2.bytepad.io/project-details?wd_id=32)
